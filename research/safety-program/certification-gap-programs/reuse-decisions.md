# Course reuse decisions for the missing certification links

This is a development crosswalk, not publication or acceptance of a new program.
Existing course IDs remain authoritative. Do not clone an existing course into
a new certification merely to give it the new certification's prefix.

## Reuse rules applied

1. Match required objectives and assessments, not only titles.
2. Reference an existing course's ID and content version/hash.
3. Add only the instruction and assessment for an uncovered objective.
4. When two new programs need the same genuinely new instruction, author one
   shared course and reference it from both once accepted.
5. Preserve existing course records, assignments and completions. Reuse does not
   authorize rewriting or deleting previously published similar courses.
6. Do not award a whole parent certification from selected constituent courses.
7. Keep unfinished material out of the source catalog and application data.

These are required coverage decisions, not a claim that every listed existing
program must be assigned in full. Final bundles must select the necessary
constituents and complete objective-level review before acceptance.

## Known overlap inside existing references

VUC008 includes reused VUC006 servicing instruction and supporting packets under
its own course IDs. New bundles should choose the original VUC006 constituents
for those shared competencies, then add only VUC008's genuinely additional
completion/subsea material when needed. Do not assign both copies to teach the
same objective. Do not delete or merge their existing records under this task.

# Work Hub audio provider decision

Status: deferred — safe-disabled adapter ships with the Work Hub foundation.

No provider credentials, data-processing terms, physical iPhone/iPad proof, or explicit provider approval were available for this release. VNDRLY therefore does not issue room tokens, start recordings, or request transcripts. The provider-neutral meeting model, consent records, and disabled adapter preserve the intended boundary without implying that audio capture is live.

Before enablement, select and approve a provider after validating web and React Native support, signed webhook replay protection, room controls, join latency, interruption and audio-route behavior, recording/transcript deletion, retention and regional terms, accessibility, observability, service limits, cost, and an exit/export path. Add credentials only through production secrets and rerun the shared adapter contract plus physical-device checks.

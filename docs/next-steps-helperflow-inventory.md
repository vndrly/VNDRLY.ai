# Next Steps helperflows

| Flow | Role and trigger | Prerequisites and next action | Saved completion and waiting |
| --- | --- | --- | --- |
| Start Your First Gate Watch | Company admin setting up Gate, assigned operator when scheduled | Authorized site → station → eligible employee with site access → shift → reviewed assignment → Assume Watch | Saved watch and its automatic ticket. Wait for shift start, the assigned operator, or ticket confirmation. |
| Watch handoff and notes | Outgoing and incoming operators at the same gate | Active outgoing watch → review open items and save notes → sign turnover → incoming review and Assume Watch | Saved notes and handoff, followed by incoming watch and ticket. Outgoing operator waits for coverage. |
| Restore staffing | Authorized supervisor or scheduler with a saved coverage gap | Saved alert → inspect exact shift → review eligible staff → save replacement assignment or personally cover when permitted | Actual watch coverage resolves the alert. A scheduled replacement can still be waiting to take over. |
| Schedule a gate shift | Authorized scheduler with an uncovered shift or station | Authorized station/date → save shift → review and save eligible assignment | Shift and eligible assignment saved. Wait for the operator to start the watch. |
| Manage gate | Authorized station editor | Authorized site → choose station → review location, links and active status → save | Saved station configuration matches the edit. A blocked edit remains in the existing editor. |
| Staff visibility | Gate Map user with staff access, on demand | Choose authorized site → Reveal Staff → choose available staff | Read-only. Wait for an available position when no current location is available. |
| Employee management | Company admin with a staffing prerequisite | Existing person or new hire → save profile → save site access and role → check eligibility | Active eligible employee at the scoped site. Wait for account setup when necessary. |
| Profile completion | Worker with a missing profile field or photo | Open own profile → enter missing details → save → upload photo if absent | Required saved profile fields and photo exist. |
| Existing credentials | Worker with a saved credential missing documentation or expired | Open own credentials → select existing record → update documentation and dates | Saved current record and supporting document. Pending review stays with the reviewer. |
| Company documents | Authorized office user with an outstanding request | Open matching document request → upload requested file → submit | Saved submission clears the upload action. Pending review remains with the reviewer. |
| Services and rates | Authorized company catalog editor with an unpublished catalog | Review services → set rates → review and publish | Saved current catalog version. A draft remains unfinished. |
